# Промпты для мультсериала (TikTok, Reels, Shorts)

Как пользоваться: откройте сессию Claude Code с этим репозиторием и вставьте нужный промпт.
Промпт 1 запускается один раз, промпт 2 — для каждой новой серии.

---

## Промпт 1: запуск сериала (один раз)

```
Хочу запустить анимационный мультсериал коротких роликов для TikTok, Instagram Reels и YouTube Shorts. Цель — смешно, качественно, чтобы досматривали до конца и пересылали друзьям.

ФОРМАТ
- Вертикаль 9:16, 1080x1920, длина 20–45 секунд.
- Язык озвучки и субтитров: русский.
- Крючок в первые 1–2 секунды (визуальный гэг или неожиданная фраза), без вступлений и логотипов в начале.
- Чёткая панчлайн-развязка в конце, по возможности — петля (последний кадр подводит к первому, чтобы ролик хотелось пересмотреть).
- Крупные субтитры по словам (стиль TikTok), читаемые без звука, не перекрываются интерфейсом платформ (безопасные зоны сверху и снизу).

ПЕРСОНАЖИ — сделай «библию персонажей» и сохрани её в проекте, чтобы переиспользовать в каждой серии:
- 2–3 главных героя с контрастными характерами (например: самоуверенный неудачник + спокойный умник + хаотичный третий).
- Для каждого: имя, возраст, внешность (силуэт узнаваем даже в чёрно-белом), цветовая палитра, характер, главная слабость, коронная фраза, манера речи, типичная реакция на проблему.
- Голос для каждого: тембр, темп, эмоциональность, и конкретный голос ElevenLabs (подобрать из библиотеки или создать через Voice Generation по описанию). Голоса должны сильно отличаться между собой. Сохрани voice_id в библии.
- Набор поз и эмоций (радость, злость, шок, хитрость, фейспалм) для повторного использования.
- Мир/место действия, где живут герои.

ЮМОР
- Предложи 10 идей серий: бытовые ситуации, понятные всем (работа, деньги, отношения, соцсети, родители, техника), через характеры героев.
- Структура каждой серии: завязка → эскалация (ситуация становится всё абсурднее) → неожиданный поворот → панчлайн.
- Комедия через тайминг: паузы перед шуткой, смена выражения лица, звуковые эффекты на реакциях.
- Без политики, без оскорблений, без чужих брендов и персонажей — только оригинальные.

ЗВУК
- Озвучка максимально живая: эмоции, интонации, разная громкость, смех, вздохи, крик — где провайдер это поддерживает.
- Звуковые эффекты на каждом гэге (бонк, свист, «вжух», запись скретч и т.п.).
- Фоновая музыка без авторских прав, приглушённая под голос.

КАЧЕСТВО
- Режим atelier (уникальная анимация), а не шаблонные сцены.
- Анимация по 12 принципам Диснея: сжатие-растяжение, предвосхищение, перебор и т.д.
- После рендера проверь сам: синхрон губ/реплик, читаемость субтитров, громкость, нет ли пустых пауз и «зависших» кадров.

ПОРЯДОК
1. Проверь, какие инструменты и API-ключи доступны, и покажи меню возможностей с ценами.
2. Предложи 2–3 визуальных стиля сериала с обоснованием и сравни Remotion и HyperFrames для этой задачи.
3. После моего выбора — библия персонажей и 10 идей серий.
4. Затем делаем пилотную серию: сначала сценарий и раскадровка на согласование, потом пробная фраза озвучки каждого героя, потом полный рендер.
Перед каждым платным вызовом говори, сколько это будет стоить.
```

## Настройка ElevenLabs (уже сделана)

- Ключ хранится в настройках облачного окружения как **Network secret**:
  сайт `*.elevenlabs.io`, заголовок `xi-api-key`, без префикса. В контейнер и в чат ключ не попадает.
- В **Environment variables** окружения стоит заглушка `ELEVENLABS_API_KEY=proxy`, чтобы инструменты
  OpenMontage видели, что ElevenLabs доступен. Настоящий ключ подставляет прокси.
- Тариф free: 10 000 символов в месяц.
- Проверка в новой сессии: «Проверь ElevenLabs: переменная ELEVENLABS_API_KEY и доступ к API».

## Что ещё улучшит качество

| Ключ | Зачем |
|---|---|
| `GOOGLE_API_KEY` | ещё голоса, картинки, музыка; щедрый бесплатный лимит |
| `FISH_AUDIO_API_KEY` | озвучка с эмоциями прямо в тексте |
| `FAL_KEY` | генерация видеоклипов (Kling, Veo) для «пиксаровского» вида, ~$1–5 за ролик |

Добавлять так же: Network secret для сайта сервиса плюс заглушка в Environment variables.
